# 삼국지 · 패업의 길

Phaser 3.90.0 기반 5대5 원정 게임. 브라우저에서 `paep/index.html`을 HTTP로 제공한다. 별도 빌드는 필요하지 않다.

## 원본과의 분리

`polos0117/atelier`의 `sam/index.html`에서 장수 279명과 인연 237개를 추출했다. 초상 267개는 바이트 변경 없이 복사했다. 초상이 없는 12명은 이름을 표시한다. 원본 HTML, 이미지, 게임 규칙, 저장 키는 수정하지 않는다.

- `core.js`: 전투 계산, 시드 난수, 편성, 성장, 원정 상태
- `app.js`: 화면, Phaser 전투와 효과, 브라우저 저장
- `data.js`: 원본 장수/인연 스냅샷
- `tests/game.test.mjs`: 데이터 무결성, 스킬 효과, 행동 검증, 재개, 원정 시뮬레이션

## 게임

촉·위·오 중 하나로 시작한다. 2명 전열/3명 후열, 예비 장수 교체, 금 60 강화(최대 5레벨), 장수 모집, 6종 보물, 9개 지역, 여포 최종전이 있다. 일반 공격은 자동, 고유기는 자동 또는 다음 행동 예약으로 발동한다. 전투당 3회의 치유/방어/집중 전술을 사용할 수 있다. 최대 250행동에서 종료한다.

23명에게 고유기, 나머지에게 역할기를 부여했다. 원본의 통솔/무력/지력/정치를 체력/공격/방어/회복 등으로 변환하며 인연당 공격력 3%(최대15%)를 적용한다. 수치는 첫 플레이 버전으로 이후 실제 플레이 피드백에 따라 조정할 수 있다.

저장 키 `sam_paep_run_v1`은 기기 로컬 저장이다. 전투 중 재개하면 저장된 시드로 해당 전투 시작부터 다시 실행한다. 기존 sam 저장 키는 접근하지 않는다. 오디오 기본값은 꺼짐이다. 모션 감소 설정을 존중한다.
