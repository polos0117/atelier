미상 2장은 원본 PNG를 gdraft-pending-style.zip으로 따로 보존했다. 원본 gdraft.zip에도 그대로 있으며 파일별 원본 이름과 해시는 manifest.json에 있다. 외형은 셀화 계열로 보이나 정확한 생성 화풍을 확정하지 않았다. 사용자 확인 없이 등록하지 않는다.
