# 격납고 메인

`../index.html`은 Babylon.js 9.22.1 기반의 3D 격납고이며, `hangar.css`와 `hangar.js`를 사용한다. 빌드 단계 없이 GitHub Pages에서 실행한다. 도감(`dex.html`), 툴킷(`prompt.html`), 게임(`play.html`)으로 이동하고 각 화면에서 격납고로 돌아올 수 있다. 기존 삼국지 링크는 격납고 설정에 남겼다.

- 전시 데이터: 기존 `lib/img.js`와 `data/img.json`, `data/mech.json`. 이름이 일치하는 기체의 등록된 초상만 사용한다. 세미리얼 시네마틱 초상이 있으면 우선하고 없으면 등록된 다른 초상을 사용한다. 선택 성별이 없으면 반대 성별로 대체한다.
- 처음 다섯 기체를 전시하며 설정의 '다음 기체 전시'로 전체 이미지 보유 기체를 순환한다. 이미지는 배경을 포함한 원본 전체를 홀로그램 패널에 표시한다.
- 전시 또는 관람 설명 링크는 `dex.html?mech=<이름>&gender=f|m`로 기존 도감 상세 시트를 연다. 이름을 찾을 수 없으면 일반 도감을 표시한다.
- 이동: WASD/방향키 또는 왼쪽 스틱. 드래그로 시점 회전. E 또는 전시 터치로 도감 진입. 벽·전시대·단말기의 발자국에 방문자 반경을 더한 충돌 처리를 사용한다. 대각선 이동 속도를 정규화한다.
- 렌더링: 기본 30fps 제한, CSS 픽셀 해상도. 절전은 0.7배, 선명은 최대 1.5배/60fps 제한. 실기기 성능을 보장하는 수치는 아니다. 정적인 구조물은 재질별 병합하며 정적인 구조물의 그림자는 1회 계산한 1024px 맵을 재사용한다. 절전에서는 그림자를 끄고, 실시간 반사 패스는 사용하지 않는다. 앱을 가리거나 일시정지하면 렌더 루프를 멈춘다.
- 엔진은 버전 고정 CDN에서, 환경 반사 텍스처는 Babylon 공식 자산에서 로드한다. 도감 이미지는 기존 공통 URL 규칙을 사용한다. 인터넷 연결이 필요하다. 엔진 실패 시 설명·재시도와 일반 메뉴를 유지한다.
- `dex.webmanifest`는 기존 설치 ID(`dex.html`)를 보존하고 `start_url`만 `index.html`로 변경했다. 기존 설치 앱의 manifest 갱신 시점은 브라우저가 결정한다. `index.webmanifest`의 설치 ID도 유지했다. 별도 오프라인 캐시나 기존 저장 데이터 변경은 없다.

자산 변경 후 `index.html`의 `hangar.css`·`hangar.js` 쿼리를 해당 파일 SHA-256 앞 10자리로 갱신한다. `draft-app.js` 변경 시 기존 README에 따라 `play.html` 쿼리도 갱신한다.

검증: `node tests/hangar-smoke.cjs` (로컬 HTTP 서버 + Playwright), `node tests/draft-engine.cjs`. Fold 커버 344×882, 내부 690×829, 가로 882×344에서 화면 경계·탭 크기, 두 손가락 이동/회전, 손을 뗀 뒤 정지, 충돌, 절전·일시정지, 도감 상세 연결, 엔진 로드 실패 시 메뉴 유지 확인. 실제 Fold5 하드웨어의 프레임·발열은 별도 확인이 필요하다.
