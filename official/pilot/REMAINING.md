## 남은 것

- **G건담 31 기** — 일부러 뺐다. 각국 대표 건담은 한 명이 한 대씩 타는
  1:1 이라 상세를 받아 봐야 이름만 다시 확인하게 된다. 인연을 넣으려면
  파일럿 카드부터 만들어야 한다
- **FREEDOM** — 목록 대조에서 새로 받을 대상이 나오지 않았다
- **비중 0.15 양산기 전부** — 인연이 붙을 일이 거의 없어 받지 않는다
- **카드가 없어 인연을 못 붙인 것** — `짐 개량형`(RGM-79C, 사우스 버닝),
  `갸르세종`(레이몬드 케인·시베트 안한). 앞의 것은 목록 대조가 0 을
  내놓는데 0083 상세에는 나오는, 대조 쪽 구멍이다

## 받을 때 주의할 것

- 마크다운으로 받는다(1크레딧). JSON 추출은 5크레딧에 키 이름도 들쭉날쭉하다
- `includeTags` 는 쓰지 않는다 — 엔진이 통째로 실패한다
- `excludeTags:["img","picture","source","svg"]` 로 분량을 줄인다
- 간헐적 실패(20% 안팎)는 `proxy:"stealth"` 로 재시도하면 대개 통한다
- 그래도 본문이 빈 채로 오면 `waitFor:4000` + `maxAge:0` 으로 한 번 더 친다
- 공식 이름과 저장소 이름이 갈리면 `gundam_match.TRANSLIT`,
  `build-bond.PERSON`(사람), `build-bond.ALIAS_MECH`(기체) 에 넣는다.
  SEED/DESTINY 쪽은 공식이 로마자로만 적어 둔 항목이 섞여 있다
