# 도감 갤러리 · 2026-10-20

book-atelier의 이미지 감상 구조를 건담 도감에 적용했다. 기존 테마·기체/파일럿/지휘관/함 분류, 작업 목록, 화풍·성별, 프롬프트 기록과 데이터는 유지한다.

- dex.html: 넓은 작품 목록과 이미지 우선 상세 펼침면. 모바일은 한 열. 전체화면에 원본 링크·이전/다음·닫기, 키보드 조작을 추가.
- lib/gallery.css: 2:3 자리 예약과 contain으로 잘림 방지. 테마 변수와 기존 스크롤 소유자를 유지.
- lib/gallery.js: 중첩 상세·감상 화면의 포커스 순환, 배경 inert, Esc와 포커스 복귀.
- tests/gallery-screen.cjs: 344·390·690·1440px의 배치 안정성·그림 감상·키보드 복귀 검사.

검증: gallery-screen, fold-layout, workspace-theme 통과. 실제 이미지로 1440×1000, 390×844 전후 화면을 비교했다.
