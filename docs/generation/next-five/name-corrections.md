# 기체 이름 정리

- `레길스`와 `건담 레길레스`를 `건담 레길레스` 한 카드로 통합했다.
- 기존 레길스 카드의 능력치·역할·등장 비중을 유지하고, 중복 카드의 형식번호 `xvm-fzc`를 보존했다. 이젤칸트 연대는 기존 두 값 중 높은 0.20을 유지했다.
- `팔라스 아테네`는 `파라스 아테네`로 변경했다.
- 해당 WebP 8개는 내용과 Blob SHA를 그대로 유지하고 파일명만 바꿨다. manifest와 체크포인트는 현재 경로를 가리킨다.
- 생성 당시 제출한 TXT 프롬프트 원문은 증거 보존을 위해 변경하지 않았다. 원문에 적힌 옛 이름은 현재 카드 이름이 아니다.
- `data/rename.json`의 이전 버전을 23으로 올려 브라우저의 기존 기록도 새 이름으로 이동하도록 했다.
